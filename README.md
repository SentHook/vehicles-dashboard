# Vehicles Dashboard

An interactive web application for exploring used vehicle sales advertisements, developed as part of the TripleTen Data Science Bootcamp.

## Features

- Explore a dataset containing 51,525 used vehicle listings.
- Visualize vehicle mileage distribution using an interactive histogram.
- Analyze the relationship between vehicle mileage and price using a scatter plot.
- Generate visualizations using interactive buttons.

## Technologies

- **Python** — Programming language.
- **Pandas** — Data manipulation and analysis.
- **Plotly** — Interactive data visualizations.
- **Streamlit** — Web application framework.
- **Jupyter Notebook** — Exploratory data analysis.

## Project Structure

- `app.py` — Streamlit web application.
- `vehicles_us.csv` — Vehicle sales dataset.
- `notebooks/EDA.ipynb` — Exploratory data analysis.
- `requirements.txt` — Python dependencies.

## Running Locally

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies with `pip install -r requirements.txt`.
4. Run the application with `streamlit run app.py`.
